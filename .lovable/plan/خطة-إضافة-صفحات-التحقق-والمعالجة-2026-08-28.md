# خطة: إضافة صفحات التحقق والمعالجة

استكمال تدفق "ساعة إليت" الوهمي بأربع صفحات جديدة تحاكي المراجع المرفقة، مع الحفاظ على الهوية الوهمية (لا شعارات بنكية حقيقية) واستخدام نفس نظام التصميم (أخضر/ذهبي، Tajawal، RTL).

## الصفحات الجديدة

1. `/verify-otp` — إدخال رمز التحقق المؤقت المكوّن من 6 أرقام
   - Hero أخضر مع شارة "حماية ثنائية" والعنوان "رمز التحقق المؤقت"
   - شارة ذهبية تعرض رقم جوال وهمي
   - بطاقة بيضاء تحوي 6 خانات OTP (shadcn `InputOTP`)، زر "تأكيد الرمز"، تنبيه ذهبي بعدم مشاركة الرمز
   - مؤقت "إعادة الإرسال خلال ‎1:49" أسفل البطاقة

2. `/hardware-token` — إدخال رمز جهاز الأمان (Hardware Token)
   - بطاقة خضراء علوية بأيقونة حاسبة وشرح "جهاز رمز الأمان"
   - بطاقة بيضاء بقائمة "خطوات التفعيل" (3 خطوات مرقمة بدوائر خضراء)
   - عدّاد دائري تنازلي (SVG stroke-dashoffset) يبدأ من 30 ثانية
   - 6 خانات OTP + زر "ربط الساعة"

3. `/app-token` — رمز من تطبيق NBE-style (نسمّيه في الواجهة "تطبيق Elite Token")
   - Header علوي أخضر مع "ربط الساعة الذكية"
   - بطاقة تنبيه بأيقونة ساعة "الخطوة الأخيرة لاستكمال طلب الساعة الذكية"
   - بطاقة بأيقونة جهاز token وزر أخضر "فتح تطبيق Elite Token" (يظهر Toast عند الضغط)
   - عدّاد دائري + 8 خانات OTP + زر "ربط الساعة"

4. `/processing` — صفحة مراجعة الطلب
   - Hero أخضر برسالة "جارٍ مراجعة طلبك"
   - بطاقة عمودية: حلقة تقدم دائرية تتحرك من 7% حتى 100% (setInterval)
   - شارتان: "الوقت المتوقع: 2 دقيقة" و مؤقت `mm:ss`
   - تنبيه ذهبي "يرجى عدم إغلاق الصفحة"
   - Timeline من 3 خطوات (تم الاستلام / جارٍ التحقق / إصدار القرار) بأيقونات حالة
   - Footer داخل البطاقة بشارات AES-256 / SSL SECURE / ISO 27001
   - عند الوصول 100% ينتقل إلى صفحة نجاح بسيطة (Toast + بطاقة "تمت الموافقة على طلبك")

## التدفق بين الصفحات

`register → login → verify-otp → hardware-token → app-token → processing → (رسالة نجاح)`
كل زر "متابعة" ينقل للصفحة التالية عبر `useNavigate` بدون أي تخزين بيانات فعلي.

## تفاصيل تقنية

- استخدام `@/components/ui/input-otp` (shadcn) — تثبيته إن لم يكن موجوداً.
- عدّاد دائري: SVG `<circle>` مع `strokeDasharray`/`strokeDashoffset` محدّث عبر `useEffect` + `setInterval`.
- كل الأرقام والأسماء وهمية؛ لا شعار بنك، لا نص "National Bank" أو "NBE" — نستبدلها بـ "Elite" أو "ساعة إليت".
- تحديث `site-header.tsx` غير مطلوب (هذه صفحات تدفق داخلية بدون تنقل عام).
- كل صفحة تحوي `head()` بعنوان ووصف فريدين.
